Este projeto aborda o desenvolvimento de um sistema para gerenciar empréstimos de itens, integrando funcionalidades modernas e um banco de dados robusto para armazenamento seguro das informações.



## Visão técnica

Aplicação desktop em Java, organizada em modelos, acesso a dados e telas. O código inclui cadastro de usuários e itens, registro e devolução de empréstimos, consulta de histórico e relatórios.

| Diretório | Responsabilidade |
| --- | --- |
| `SistemaEmprestimosItens/src/model/` | Entidades do domínio |
| `SistemaEmprestimosItens/src/dao/` | Acesso a dados |
| `SistemaEmprestimosItens/src/conexao/` | Conexão com o banco |
| `SistemaEmprestimosItens/src/sistema/` | Telas e fluxos da aplicação |
| `banco` | Script do banco de dados |

## Como explorar

1. Abra `SistemaEmprestimosItens` como projeto Java no NetBeans.
2. Confira as bibliotecas e a versão de Java exigidas na configuração do projeto.
3. Prepare um banco local compatível com o script `banco` e ajuste a conexão no seu ambiente.
4. Execute a aplicação pelo IDE e percorra os fluxos de cadastro, empréstimo e devolução.

A execução não foi validada nesta revisão de documentação.
